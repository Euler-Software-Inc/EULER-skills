EULER is a Claude Code plugin: 9 skills that orchestrate the remote EULER MCP into one-prompt partner workflows — QBRs, briefings, portfolio pulse, approvals triage, and partner self-service. Each run returns a self-contained, branded HTML report.

Install in Claude Code

> /plugin marketplace add Euler-Software-Inc/EULER-skills
> /plugin install euler@euler-plugins

First invocation triggers a one-time OAuth consent against mcp.eulerapp.com — the token is cached for 30 days.

How it works

Install once, then just ask.

Skills are model-invoked playbooks. Type a slash command or describe the intent — Claude reads the playbook, calls the EULER MCP tools, and formats the result.

1

Install the plugin

Add the marketplace and install euler@euler-plugins — no server to run.

2

Invoke a skill

Type /euler:generate-qbr or just ask: "QBR for Lumon Industries."

3

Connect once

A one-time OAuth 2.1 consent to mcp.eulerapp.com; the token is cached.

4

Get a branded report

Claude orchestrates the MCP tools per the playbook and returns self-contained HTML.

Connector vs. plugin. The EULER connector gives anyone on Claude.ai raw MCP tool access. The plugin layers curated, one-prompt workflows — skills — on top, bundling the expertise into a single invocation.
